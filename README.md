# Komentář k zákonu č. 151/2010 Sb., o zahraniční rozvojové spolupráci a humanitární pomoci poskytované do zahraničí a o změně souvisejících zákonů

Otevřený komentář k zákonu o zahraniční rozvojové spolupráci a humanitární pomoci — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; pojmy a formy rozvojové spolupráce a humanitární pomoci, působnost Ministerstva zahraničních věcí, Česká rozvojová agentura a působnost dalších orgánů.

Konsolidované znění: dokument e-Sbírky `SB-2010-00151_2022-01-01`.
